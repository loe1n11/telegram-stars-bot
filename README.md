# Telegram Stars Bot

Telegram бот для продажи Telegram Stars с поддержкой платежей через WATA и TON.

## Описание

Бот предоставляет информацию о продаже звезд и отвечает на вопросы, связанные с информацией, аккаунтом пользователя и другими темами, не связанными с покупкой.

## Функционал

- 📋 Информационные сообщения
- 👤 Профиль пользователя
- 💰 Информация о ценах и тарифах
- 🔔 Поддержка уведомлений

> **Примечание:** Функционал покупки звезд находится в разработке и будет добавлен позже.

## Требования

- Python 3.9+
- python-telegram-bot >= 20.0
- aiohttp

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Токен бота

Используется токен Telegram бота для взаимодействия с Telegram API.
